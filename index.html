โครงสร้าง Rooted Tree (บทที่ 7)

ระบบจัดเก็บหมวดหมู่เครื่องเล่นด้วย **Rooted Tree 4 ระดับ** เพื่อใช้ไล่ระดับเลือกสถานที่ (Root → Zone → Category → Leaf):

  • Level 0 (Root): WonderPark
  • Level 1 (Internal): Zones (e.g. Thrill Zone)
  • Level 2 (Internal): Category (e.g. Extreme Rides)
  • Level 3 (Leaf): Attraction (e.g. Dragon Coaster)
Leaf คือสถานที่จริงที่ใช้เป็น Vertex ในการคำนวณ Graph

หลักการทางคณิตศาสตร์ดิสครีต: Weighted Graph & Dijkstra Algorithm

ระบบใช้คำนวณ Shortest Path ตามขั้นตอน Dijkstra โดยตั้งค่าระยะทางเริ่มต้น $dist[s] = 0$ และจุดอื่น $dist[v] = \infty$ แล้วเลือก Vertex ที่มี Cost น้อยที่สุดที่ยังไม่ถูกปิด ตรวจสอบ Neighbor และทำการ Relax ค่า weight

1. เดินเร็วที่สุด: Cost = Time
2. เวลารอน้อยสุด: Cost = Queue
3. เส้นทางสมดุล: Cost = Time + (Queue × 0.5)
